# 비만·신체활동이 암 발병 위험에 미치는 영향
### Cox 비례위험회귀분석 + YAP/TAZ 세포 신호 미분방정식 모델링

국민건강영양조사(HN24, 2024) 원시자료를 이용해 비만(BMI)·신체활동·공복혈당이
암 진단 위험과 어떻게 연관되는지 통계적으로 분석하고, 그 통계 결과가 실제
세포 수준의 YAP/TAZ 신호 메커니즘과 부합하는지를 미분방정식 모델과 역방향
디버깅으로 검증하는 Streamlit 앱입니다.

---

## 1. 폴더 구성

앱을 배포하거나 실행하려면 아래 4개 파일이 **모두 같은 폴더**에 있어야 합니다.

```
.
├── main.py              # 앱 실행 파일 (Streamlit 진입점)
├── cox_model.py          # Cox 비례위험회귀 계산 모듈 (numpy 전용 자체 구현)
├── yap_taz_model.py       # YAP/TAZ 미분방정식 모델 모듈 (numpy 전용 자체 구현)
├── hn24_cox_data.csv      # 분석용 정제 데이터
└── requirements.txt       # 의존 패키지 목록
```

## 2. 로컬 실행 방법

```bash
pip install -r requirements.txt
streamlit run main.py
```

## 3. 이 앱이 배포 오류에 강한 이유

과거 배포 시 `ModuleNotFoundError: No module named 'plotly'` 같은 에러가
반복됐던 원인은 `lifelines`, `scipy` 같은 무거운 통계·수치계산 패키지가
클라우드 환경에서 설치에 실패하거나, `requirements.txt` 인식 문제로
설치 자체가 안 되는 경우였습니다.

이 버전은 그 원인을 구조적으로 제거했습니다.

- **Cox 회귀**: `lifelines` 없이 `cox_model.py`에서 Newton-Raphson으로
  부분우도(partial likelihood)를 직접 최대화하도록 numpy로 구현했습니다.
  `lifelines`의 계산 결과와 소수점 셋째 자리까지 일치함을 확인했습니다.
- **미분방정식 수치적분**: `scipy.integrate.odeint` 없이 `yap_taz_model.py`에서
  4차 룽게-쿠타(RK4)법을 numpy로 직접 구현했습니다.
- **카플란-마이어 생존곡선**: `lifelines.KaplanMeierFitter` 없이 numpy로
  직접 계산합니다.

따라서 이 앱이 필요로 하는 외부 패키지는 `streamlit`, `pandas`, `numpy`,
`plotly` 4개뿐입니다. `requirements.txt`도 이 4개만 담고 있습니다.

## 5. 앱 구성

### 탭 1 — Cox 비례위험회귀분석
- 실제 HN24 자료(만 19세 이상, 5,268명, 암 진단 340건)로 위험비(HR)를 계산합니다.
- 분석에 포함할 변수(BMI, 신체활동, 공복혈당, 나이, 성별)를 직접 선택할 수 있습니다.
- 결과를 forest plot(위험비·신뢰구간)과 신체활동 유무별 카플란-마이어
  생존곡선으로 시각화합니다(plotly).
- 로지스틱 회귀 대신 Cox 회귀를 쓰는 이유, 모형의 수학적 구조를
  펼침 박스로 설명합니다.

### 탭 2 — YAP/TAZ 미분방정식 모델
- 다음 연립미분방정식을 파라미터 조절이 가능한 형태로 시뮬레이션합니다.

  ```
  dY/dt = α·A − β·M·Y − γ·Y
  dC/dt = r·C(1 − C/K) + δ·Y·C
  ```

- Y(t): 핵 내 활성형 YAP/TAZ 농도, C(t): 암세포 수
- α, β, γ, δ, A, M, r, K 8개 파라미터를 슬라이더로 조절할 수 있고,
  각 슬라이더에 생물학적 의미를 설명하는 도움말이 붙어 있습니다.
- 각 항이 왜 그런 형태(질량작용 법칙, 로지스틱 성장모형 등)인지
  단계별로 설명하는 펼침 박스를 포함합니다.
- YAP 정상상태(steady-state) 해석해 Y* = αA/(βM+γ)를 함께 제시하고,
  운동 강도(M)에 따른 Y*의 변화를 그래프로 보여줍니다.

### 탭 3 — 역방향 디버깅
- 탭 1의 실제 Cox 회귀 결과(신체활동의 HR)와 탭 2의 미분방정식이
  예측하는 방향이 일치하는지 자동으로 비교합니다.
- 이 데이터에서는 신체활동의 HR이 1보다 크게(약 1.4) 나와 미분방정식
  모델의 예측(운동 → 암 위험 감소)과 모순되는데, 이 모순을 실마리로
  ① 역인과관계, ② 건강검진 접근성 교란, ③ 표본 내 사건 수 부족이라는
  세 가지 원인 후보를 소프트웨어 디버깅과 같은 논리로 짚어봅니다.
- Y*(M) 함수가 수학적으로 항상 감소함을 그래프로 보여주어, "파라미터
  값이 아니라 모델의 함수 형태(구조) 자체가 관측 패턴을 재현할 수
  없다"는 결론을 도출합니다.

## 6. 데이터 출처 및 주의사항

`hn24_cox_data.csv`는 질병관리청 국민건강영양조사 제9기 2차년도(2024,
HN24) 원시자료 중 만 19세 이상 성인의 암 진단 여부, 진단 시 나이,
BMI, 유산소 신체활동 실천율, 공복혈당, 나이, 성별만 추출·정제한
파생 데이터입니다.

- 암 진단자: `event=1`, `time=진단 시 나이`
- 암 비진단자: `event=0`, `time=현재 나이` (중도절단)

이 자료는 **단면조사(cross-sectional)**이므로, 신체활동 수준과 암
진단 여부가 같은 시점(2024년)에 측정되었다는 한계가 있습니다. 즉
"운동이 암을 예방했다"는 인과관계를 확정할 수 없으며, 역인과관계나
교란요인의 가능성을 배제할 수 없습니다. 탭 3의 역방향 디버깅은
바로 이 한계를 데이터에 기반해 구체적으로 짚어보는 과정입니다.
